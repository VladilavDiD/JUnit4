# Code Review: Main.java

## Загальні зауваження

1. Назва класу `Main` не інформативна. Краще використовувати щось типу `CalculatorApp`.
2. Весь код зібрано в одному класі — варто винести частини логіки в окремі класи.
3. Відсутній коментар до коду. Бажано додати Javadoc для методів.
4. Присутнє дублювання коду (використання `Scanner` кілька разів).
5. Погано структурована логіка — метод `main()` виконує забагато.
6. Не обробляються винятки (наприклад, ділення на нуль).

## Рекомендації

- Виділити логіку калькулятора в окремий клас.
- Зробити клас для зчитування введення.
- Дотримуватись Java Code Style (відступи, назви, форматування).
